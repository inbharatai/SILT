Local-first Studio

Run SILT Studio on your machine.

The public SILT site is the documentation and launch surface. The actual Studio runs on your own computer at 127.0.0.1:8377, so your local models, skill packets, benchmarks and audit state do not need to pass through Vercel.

If “Open Local Studio” cannot connect, start the local engine using the steps below.
Privacy boundary: 127.0.0.1 always means the visitor's own machine. This page does not expose your Studio to the internet and does not proxy private model traffic through the hosted SILT website.
01

Install SILT

Clone the open-source repository and install the Studio dependencies locally.

02

Start the engine

Bind SILT Studio to loopback on port 8377. Keep it local; do not expose it on 0.0.0.0.

03

Open Studio

Return here and click Open Local Studio, or browse directly to http://127.0.0.1:8377/.

Quick start

git clone https://github.com/inbharatai/SILT.git cd SILT python -m pip install -e ".[studio]" python -m uvicorn asea.studio.server:app --host 127.0.0.1 --port 8377

Requires Python 3.9 or newer. Optional real-model connectors and deep-apply dependencies can be installed separately from the repository when needed.

Then open

http://127.0.0.1:8377/
Launch SILT Studio

Why not host the whole Studio on Vercel?

SILT Studio is designed around local model runtimes, local files, local audit state and potentially large model weights. Hosting the control page is easy; moving every user's private model workload into a public cloud service would change SILT's security and privacy model. The local-engine architecture keeps the compute and data where the user chooses to run them.
