SILT · Skill Interchange Layer with Trust-gating

Transfer the skill. Prove the gain. Adapt for the hardware you have.

A powerful model can still be missing one specialist capability. Another AI may already have it. SILT pursues reusable narrow capabilities across models: inspectable skill transfer, measured admission, and hardware-aware adaptation. Its separate experimental source-weight path constructs smaller specialists, trains recovery factors, and exports teacher-independent serving bundles. Construction is implemented; retained quality remains unproven.

The SILT thesis

A model should not need to know everything from birth.

If the model you want to deploy is strong but lacks one measurable capability — a language, terminology set, task pattern, workflow, or other narrow skill — SILT asks whether that capability can be represented, transferred from a specialist system, and admitted only after evidence shows the learner improved.

Read the status, not just the feature name.

Implemented ≠ enabled ≠ measured ≠ admitted ≠ active. Installing or merging code starts no model run and grants no certificate.

Transfer → Prove → Adapt

Three stages, one discipline: do not confuse a process completing with a capability improving.

01 · TRANSFER

Represent a narrow skill

The default L3 path creates an inspectable Skill Packet containing capability-specific material such as rules, mappings, glossary entries, exemplars, or structured instructions. The teacher's weights are not copied.

02 · PROVE

Evaluate beyond extraction

Held-out cases are separated from this extraction workflow—not guaranteed unseen in pretraining. SILT compares baseline and candidate on supplied suites, checks declared provenance, regressions and safety tripwires, then returns PROMOTED, REJECTED, or, only when otherwise eligible and missing approval metadata, PENDING_HUMAN.

03 · ADAPT

Fit the deployment constraint

Optional deep-apply can train a removable LoRA from already-approved packets and gate it again. SiltSpring measures quantized-state loss against operator-provided suites and a resident reference. A separate experimental path reconstructs smaller models from source weights and applies teacher-guided recovery; construction completion is not quality certification.

Architecture at a glance

The trust gate is the enforcement layer — not the whole purpose.

SILT separates how a capability is produced from whether the result is allowed into the learner. The default packet pipeline uses capability/modality-specific plugins; optional training, composition, compiler and specialist workflows have distinct activation and evidence contracts. HF causal/seq2seq and Ollama connectors require configured models. Legacy TTS packets carry symbolic G2P text—not voice timbre or acoustic prosody.

DEFAULT WHEN RUN · L3

Skill Packet mode

Approved skill material is used at inference time. No learner weights are changed. Candidate, approved, and rejected states remain physically separated.

OPTIONAL BACKEND · L4

Deep-apply + Gate 2

Explicit packet-derived deep-apply trains LoRA from Gate-1-approved packets, then benchmarks the adapter again. These adapters remain removable, not merged into base weights. Gate 2 inherits source-packet safety scores; it is not a comprehensive trained-output safety audit. Training completion alone does not admit an adapter.

OPTIONAL BACKEND

SiltSpring

Explicit int8/int4/int2 reports compare next-token loss on operator-provided suites; held-out-only filtering is not automatic. The real-HF path needs a full resident reference. Toy state-selection, serving and staleness safeguards are not the real Studio report path. Neither decoder-layer bytes nor loss thresholds prove whole-device fit or task quality.

Implemented portfolio · distinct paths, one narrow-capability thesis

Source weights → smaller specialist → recovery → independent serving

Alongside packets, the experimental specialist workflow implements source validation and calibration, coherent reconstruction, reconstructed validation, teacher-guided recovery, and recovered validation. Export/reload checks and a separately invoked frozen final comparison follow their own contracts. BUILT_UNCERTIFIED means engineering complete—not quality passed or active deployment.

OPTIONAL BACKEND

SiltStream

Select streamed for layer-streamed LoRA with disk-backed frozen decoder layers. Real-HF parity checks sampled pre-training forward logits—not identical gradients or learned weights. Full resident loading/parity is still required before streaming. Supported model/runtime and memory limits apply; a prepared GPU probe is not a measured GPU result.

OPTIONAL BACKEND

ZeroForge

Select zeroforge for forward-only, zeroth-order LoRA updates using SPSA-style perturbations. Zero backward passes still means multiple forward passes per update, resident loading/parity, and real memory costs. Small-model CPU backprop also exists; this is neither free compute nor a general speed, quality or GPU-independence advantage.

OPTIONAL BACKEND · EVALUATOR API

Asymmetric SPRT

Explicitly configure the evaluator with SprtConfig to stop sufficiently negative candidate evaluations early. It never early-promotes; a surviving candidate still faces the ordinary full-suite gate. SPRT is off by default, and nominal statistical error settings depend on the test assumptions—not universal confidence in model quality.

LOCAL DIAGNOSTIC

Signed Capability Diff

Request diff and diff-verify to compare approved-set snapshots, packet-content changes and held-out capability scores. CapabilityDiff reports use a local HMAC key: verification establishes holder-key integrity, not externally authenticated authorship or factual correctness. Results cover the supplied suites, receiver and runtime—not differences inside model weights.

LOCAL DIAGNOSTIC

Skill-layer Unlearning

After explicit snapshot/rollback operations, unlearn checks managed packet removal and behavior returning within tolerance of the native baseline. A substantive result also requires prior measurable lift. Its local ErasureCertificate is suite-limited evidence—not deletion of weights, LoRA factors, audit history, or knowledge retained by a stateful connector.

EXPERIMENTAL OPT-IN

Structural compiler

The separate native Switch compiler physically prunes experts and router rows, exports weights, and offers diagnostics, identity roundtrips and research scoring. Certification is a separate narrow seq2seq-text operation; pruning is not admission. Compiler repair-training remains unsupported, even though specialist recovery exists. This is not an arbitrary MoE or frontier-model compiler.

EXPERIMENTAL OPT-IN

Coherent reconstruction

Qwen2 reconstruction physically slices aligned MLP channels while retaining learned attention/backbone weights. Switch reconstruction selects source experts into a genuine dense T5—not the compiler's keep-N Switch model. Explicit local source weights and calibration are required. These are implemented family-specific transformations; RECONSTRUCTED_UNVALIDATED does not establish retained quality.

EXPERIMENTAL OPT-IN

Recovery & teacher-independent export

Specialist recovery trains actual LoRA factors with teacher KL and supervised response loss. Native-merged export requires parity checks; the recorded BF16 merge failed. Recorded factor-preserving bundles serve without the teacher/cache but require complete base, factors, tokenizer and matching SILT/PEFT runtime—not plain HF-root or GGUF loading. Engineering admission is not quality admission.

EXPERIMENTAL OPT-IN

Portable artifacts, fresh trust

Explicit dependency-inclusive Compose export and bounded import validate inventories and rebind model paths. Imports remain unadmitted until fresh local evaluation; selection and import never activate automatically. Same-host relocation is not clean-machine certification. Separately, legacy packet export produces inspectable datasets and L4/L5 job recipes marked unexecuted—not trained checkpoints.

EXPERIMENTAL OPT-IN

Composition & speech bridges

Compose runs typed linear chains of 1–16 locally provisioned nodes, not arbitrary branching or latent fusion. Text-mediated Whisper ASR and Vits/MMS TTS use bounded inputs and CPU float32. Audio-output quality admission remains blocked; waveform/listening packets stay pending-human, not intelligibility or MOS certificates. Model licensing still constrains use.

EXPERIMENTAL OPT-IN

Matched vision → text

The matched SmolVLM/Idefics3 model and processor accept bounded images plus a question, producing text that can feed text/TTS nodes. Provision the complete local model and required Transformers runtime. This is an implemented image-to-text bridge—not a standalone encoder attached to any LLM, broad OCR certification, or arbitrary cross-modal capability transplantation.

EXPERIMENTAL OPT-IN

Governance & observability

Explicit validation registries, consumed final reservations, external function-IO grading, generation/oracle traces and resource probes expose what ran and failed. Linux process_as limits virtual address space—not aggregate RSS; observe-only does not enforce. Traces require retention choices, local records are not independent custody, and unsupported Windows/cgroup execution fails closed.

Evidence controls have boundaries.

Core safety checks are rule-based tripwires; provenance depends on trusted declarations and regression coverage on supplied suites. For declared medical/legal/finance domains, approval metadata is mandatory under the normal gate, but the caller-supplied approver name is not verified human review. Only otherwise-eligible candidates without that metadata become pending; other failed checks reject.

Hash-chained audit records, runner telemetry, local HMAC reports and retained traces are different evidence types—not external authentication. Mock fixtures demonstrate mechanics, recorded model runs support bounded results, and neither automatically establishes broader capability. See the activation catalog for exact defaults, platform bounds and evidence links.

Honest scope

What SILT claims — and what it does not.

What exists in the repository

  • Inspectable L3 Skill Packets and held-out A/B evaluation.
  • All-or-nothing admission over emitted checks under the chosen policy, with supplied regression suites, safety tripwires, declared provenance, rollback and audit controls.
  • Mandatory caller-supplied approval metadata for declared high-risk medical/legal/finance domains—not verified human identity.
  • Optional removable LoRA deep-apply followed by an independent Gate 2.
  • Optional SiltStream, ZeroForge and loss-based SiltSpring reports; opt-in SPRT and local Capability Diff/skill-layer Unlearning diagnostics.
  • Local Studio, CLI, library interfaces, examples, tests, and recorded real-run findings.
  • Experimental source-derived reconstruction, recovery and export; composition, matched media bridges, compiler, governance and portability. Full activation catalog; completed models remain uncertified.

What SILT does not claim

  • Universal arbitrary capability copying between any two models.
  • Complete transfer of a teacher model's knowledge or internal weights.
  • AGI or unrestricted autonomous self-improvement.
  • Demonstrated frontier-model reconstruction, arbitrary billion-parameter models on 4 GB, or universal GPU/Windows validation. Full-reference loading still constrains streaming paths.
  • A fabricated percentage of “knowledge transferred.” SILT reports measurable benchmark deltas and gate verdicts instead.
  • A universal safety guarantee: a gate can only measure what its tests and policies cover.
  • Patent novelty for standard LoRA or coverage of the new reconstruction/recovery mechanisms by the existing provisional.
SILT Studio

Use Studio locally. Choose where model inference runs.

The local Studio configures transfers, gate decisions, approved-skill tests, audit review, deep-apply and Spring reports. This homepage and public /studio/ are static discovery/setup pages—not a running or hosted engine. Start the local service before opening 127.0.0.1:8377. Privacy depends on the selected endpoint: local orchestration does not make remote or cloud-backed inference local.
